Controls & setup

Quest 3: use the standalone Meta Quest Browser. Enter AR and allow spatial data access. If no surfaces appear, use Set up room or run Space Setup in the headset settings.

Trigger: point at the floating menu to choose an action, or elsewhere to launch a ball.
Right grip: pin / unpin light.
Left grip: bring menu in front of you.

Desktop: drag to orbit, scroll to zoom. The room is synthetic; it previews the same rendering and physics used in AR.

Reality ↔ Mesh: pinch both hands or hold both controller triggers with your hands close together, pull apart, then release. Repeat to return. The floating menu also has Tear / Return buttons.

Light overlay colors and dims scanned surfaces. Virtual room replaces those surfaces with lit geometry. Neither removes the lighting already present in the camera image.
